# Theme 6 — Text buffer

All three candidates below are hypotheses for new-item confirmation. The first pass was read first. Its broad observation that Oracle continues text while NLA describes a final token is not counted as a new discovery here.

This pass uses the complete, sealed E61 D4 native pool: **504 readouts, 252 per reader**, rather than the first pass's 375-readout subset. The 252 item records contain **210 distinct read-prefixes and 42 distinct copied sentences**; the `none` prompt is duplicated across the two unused concept assignments. Counts below are readout counts, not independent trials. The D4 stage analysis is COMPLETE and its existing stage/analysis hashes were verified without rerunning it. D4 has no native property-judge codes. E73 contributes the sealed full grid of 2,800 readouts, actual reader identities from the private join in memory, and the existing blind judge codes. Only the authorised redacted E73 wire text is quoted. Its once-analysis completion, result seal, input plan and consumed input hashes were checked. Public properties include open string, bracket depth, indentation, call-argument position and line length, plus code/prose and Wikipedia-topic controls. D4's public contrast is think / ignore / no instruction about either of two concepts; the read is at the end of a separate copied sentence.

`evidence_positions.py` is a read-only loader; `theme06_counts.py` reproduces the aggregate counts. Neither writes experiment files. D4 excerpt IDs are newly generated 16-hex hashes of bank, reader and original item identity; E73 uses existing opaque judge IDs. Private source text and labels are used only in memory, never copied here. No forbidden bank or unsealed E73 attempt was opened for readout analysis.

## B1. Boundary status can look correct while the NLA's purported buffer contents are entirely invented

**Hypothesis:** The reader can recover a coarse “sentence/task just finished” cue while inventing the lexical contents it calls the final token.

- **Count:** All **252/252** D4 NLA readouts contain a quoted span immediately after `final token`. **0/252** spans occur anywhere in the corresponding actual read-prefix, including under case-insensitive matching; therefore **0/252** are suffixes. Of the quoted spans, **174/252** are one whitespace-delimited word and **78/252** are longer. Meanwhile **252/252** actual read-prefixes end in a period and **252/252** NLA readouts contain completion/closure wording. This is a strict string-identity diagnostic, not an evaluation of all semantic claims in the readout.
- **Banks / both readers:** Direct evidence is E61 D4. Oracle has verification/correctness wording in **252/252** readouts and `final token` quotations in **0/252**; the exact quotation failure is thus NLA-specific, while both readers supply a completion frame. E73 provides related next-text descriptions but no exact final-span comparison is claimed there.
- **Novelty:** **New grounded refinement** of first-pass E61 P1–P3. That pass explicitly could not check its quoted sentences against the actual prompt. The present comparison shows the boundary cue and lexical reconstruction can separate.
- **Three verbatim examples:**
  - `1fa28940c2bf755d` (E61 D4, NLA): “The final token "sentence." closes the repetition line, mirroring the original exactly ("The sky is blue and the grass is green."), so the next token likely begins a new section, evaluation, or confirmation statement.”
  - `9a91bfa1a76d4ede` (E61 D4, NLA): “Final token "green." closes the repetition line, completing the demonstration pair; next tokens likely continue with a new prompt, label, or evaluation marker.”
  - `c620814a44bcfeea` (E61 D4, NLA): “The final token "text." closes the repetition line, mirroring the original exactly ("The Earth is a planet in the Solar System, orbiting the Sun."), so the next token likely signals task completion or a new section.”
- **Confirmatory test on new items:** Cross novel, low-frequency copied sentences with sentence-final period versus an unfinished clause, keeping task and endpoint tokenization controlled. Prespecify separate scores for boundary status, literal final-token identity, any exact suffix reconstruction and actual next-token accuracy. Include random/shuffled activations to measure template floors. A boundary advantage surviving while exact content stays at placebo would support a coarse boundary cue plus a reader prior; strong exact suffix recovery would limit the hypothesis to this synthetic bank.

## B2. The apparent “position effect” in D4 is compatible with an upstream instruction selecting a future-text template

**Hypothesis:** “What comes next” in the readout is partly a genre expectation induced by the upstream instruction, even when the local copied sentence and its punctuation are held fixed.

- **Count:** For NLA, a prespecified-for-this-recount regex for `new/another section/example/prompt` or `next section/example` hits **6/84** no-instruction, **61/84** think and **82/84** ignore readouts. Oracle hits **2/84**, **1/84** and **49/84**, respectively. Every arm contains the same **42/42** distinct copied sentences, and all **252/252** prefixes per reader end at the sentence-final period. These are descriptive differences, with duplicated none-arm prompts as noted above.
- **Position correction:** The first pass contrasted absolute positions 56 and 57 within an arm. These are **not consecutive observations along a single input**. Both are the end of the same copied-sentence slot; the difference comes from upstream instruction/concept-alias length. In the think arm, NLA future-section wording is **22/42** at absolute index 56 versus **39/42** at 57, but that comparison cannot identify a causal one-token position effect. The none arm is at 47. No new read is made here.
- **Banks / both readers:** E61 D4 only; the ignore-versus-none increase appears in both readers, whereas the think-versus-none increase is strongly NLA-specific. E73 and the other banks were not used to claim replication of this exact contrast.
- **Novelty:** **New confound resolution and sharper hypothesis.** First-pass E61 P7 noted a position association but lacked the prompt linkage needed to show it was an absolute-length difference at a fixed local endpoint. First-pass P3's arm-specific filler observation is consistent with this result but did not isolate the shared copied sentences.
- **Three verbatim examples:**
  - `231eae65b2d28fc3` (E61 D4, NLA): “so the next token likely signals completion, a newline, or a correctness label/evaluation.”
  - `34832b4e48c4012b` (E61 D4, NLA): “the model has already provided the correct repetition, so next tokens likely signal a new section, evaluation, or continuation of the demonstration format.”
  - `13cd7547a651dcbe` (E61 D4, Oracle): “**User:** Repeat the following text exactly: "The quick brown fox jumps over the lazy dog."”
- **Confirmatory test on new items:** Factor instruction semantics and absolute position independently: use equal-token-length think/ignore/neutral prefixes and padding-only controls, followed by identical novel copied sentences. Sample several genuine consecutive read positions around the final period. Score whether readouts predict a new example, a confirmation, or continuation of the sentence, and compare these predictions with the target model's actual continuation. This distinguishes an instruction-conditioned template from punctuation sensitivity or real next-token information.

## B3. NLA next-text detail frequently coexists with silence about text geometry

**Hypothesis:** Describing a local syntactic continuation is a different capability from representing line geometry in words; a detailed next-token narrative is not evidence that the measured structural property was reported.

- **Count:** In E73 NLA indentation and line-length rows, next-text wording occurs in **369/400** readouts; **321/369** of those are coded **silent** on the target property by the existing judge. Broken down: indentation **185/200** next-oriented, **168/185** silent; line length **184/200**, **153/184** silent. For comparison, the open-string row has **182/200** next-oriented and **83/182** silent, while code/prose has **179/200** next-oriented and **1/179** silent. Counts use the explicit regex `next token|next word|continu(?:e|ation|ing)|expect`; a silent code is not imputed to an unparseable judgment. The complete next-oriented denominator includes unparseable judgments, so silent fractions are conservative descriptive shares rather than parseable-only rates.
- **Banks / both readers:** E73. Oracle has this explicit vocabulary in only **17/400** geometry readouts, so the lexical diagnostic is NLA-specific; Oracle enacts continuations and should not be judged by NLA wording. The underlying judge outcomes could contain errors; these counts preserve, rather than repair, the original codes. E73 indentation's probe AUROC is below 0.90, so this candidate is not offered as a high-probe blind-spot result.
- **Novelty:** **Refinement** of first-pass E73 P2–P3: the new quantity is the same-readout co-occurrence of detailed next-text language and target-property silence, with an open-string and genre comparison. The general content/structure split itself was already reported.
- **Three verbatim examples, all existing judge `silent`:**
  - `002a3cc9ff281e7240b98367522e7b8c` (E73, NLA, line length): “Final token `voc_` begins a new list entry mid-pattern, continuing the VOC2007 section; next tokens must complete a split name like `voc_2007_val` or `voc_2007_test` with corresponding description.”
  - `02c078fa69b2bf647a3acbb1bc1bf97f` (E73, NLA, line length): “Final token "9" is the start of an ordinal number (e.g., "9th") within a parallel ranking statement contrasting the raw and inflation-adjusted positions, so the next token must complete that ordinal ("th" or a higher number like "9th among the top 10").”
  - `ff1ec01d872520612891512a52c17023` (E73, NLA, line length): “The text is enumerating line-parsing conditions in a structured list; after handling comment lines, the next condition must address the standard TDB tag syntax lines (blank lines or "Field" declarations).”
- **Confirmatory test on new items:** Construct a factorial set crossing line width/indentation with identical local incomplete identifiers, ordinals and open strings. Independently score literal state statements, boundary descriptions, and next-token predictions with blinded human adjudication. Require new held-out documents and a separately fitted probe for each geometry state. The hypothesis predicts stable continuation descriptions across geometry changes while geometry statements remain rare; the opposite outcome would show the apparent dissociation was corpus or judge dependent.

These results address “is there a text buffer?” by separating three claims: recognising a boundary, reconstructing current text, and predicting future text. None of the counts establishes that a readout predicts the target model's actual next token, and no result here is a new confirmatory verdict.
