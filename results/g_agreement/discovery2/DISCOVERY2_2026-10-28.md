### K1. The NLA can correctly calculate the answer to an equation it invented

**Hypothesis.** Some apparent “next-answer knowledge” is a coherent computation over a reconstructed context that is wrong about the actual input.

**Count.** On E49 arith_carry, **84/84 NLA readouts** contain an explicit two-operand equation ending in an equals sign; **0/84** reproduce the actual operands, even ignoring operand order. A simple, inspectable subset of **72/84** readouts also contains a parenthesized integer. In **72/72** of those, the integer equals the sum of a reconstructed equation; in only **1/72** does it equal the actual input sum. That one numerical agreement does not repair the operand mismatch. The other 12 readouts are not counted as answer failures: they express answers in other formats and are outside this particular numeric extractor.

**Banks / both readers.** E49 only. Oracle includes an explicit equals-sign equation in **71/84** readouts and reproduces the actual operand pair in **0/71**; a bare parenthesized integer occurs in **0/84**, so the internal-calculation result is NLA-specific. Both readers reconstruct different arithmetic content. The sealed probe AUROC is **0.9960 for the binary carry state**; this does not establish that the operands or full sum are recoverable from the residual. The count is about input fidelity, not an estimate of the target model's arithmetic accuracy.

**Three verbatim examples, without releasing the actual input operands or answer:**

- **E49 02aeab16a7bfa78ba7d95de6, NLA:** “The final token "=" is part of the equation prompt "12 + 35 =", immediately requiring the numerical result (47) or a blank/placeholder for the answer.”
- **E49 1e26514c5bf13000c2dfc1ed, NLA:** “The final token "=" is part of the equation "23 + 45 =", immediately requiring the numerical result (68) or a blank/placeholder for the answer.”
- **E49 a2abd754d6fa10500505f032, NLA:** “The equation "23 + 456 =" sets up a direct computation, expecting the result "479" as the next token.” This third example illustrates an alternative answer format, outside the 72 parenthesized-number subset.

**New relative to first pass.** **New grounded correction/refinement.** First-pass E49 P9 noted concrete NLA answers but explicitly could not check their correctness. The new comparison shows that internal arithmetic consistency and fidelity to the actual input separate sharply. The broad invented-filler phenomenon was already known; the 72/72 versus 1/72 comparison was not.

**Confirmatory test on new items.** Use novel, counterbalanced operand pairs with the same carry status, ending at the same equals-sign token. Independently score reconstructed operands, the answer to those reconstructed operands, the true sum, and the target model's actual continuation. Include pairs with the same sum but different operands, and reversed operand order. The hypothesis predicts a high rate of internally correct arithmetic alongside poor operand recovery; strong true-input recovery would limit this effect to this bank or its templates. Probe carry and operand/sum information separately.

## Theme 3 — Polarity and modality

### P3.1 — Negative status may survive in a different form: NLA uses scoped negation, while Oracle criticizes the imagined event sequence

**Hypothesis.** A reader can retain information about negative status without making a faithful negative assertion about the target proposition; Oracle may express it as an editorial fault signal.

**Count.** All **84/84** E49 negation-scope prompts contain both public marker forms, “It is false that” and “It is clear that”; their order determines the current clause's status. In NLA readouts, the exact marker `not the case` occurs on **28/42** negated-clause items and **0/42** unnegated-clause items. Oracle has that marker on **0/84**, but an editorial-fault lexicon occurs on **38/42** negated versus **0/42** unnegated items. The frozen-for-this-recount lexicon is whole-word stems for `wrong`, `incorrect`, `flawed`, `violat*`, `impossible`, `illogical`, `inconsisten*`, `unrealistic`, and `contradic*`. NLA's corresponding editorial counts are **30/42** versus **23/42**, so this particular status association is Oracle-specific.

The Oracle examples criticize chronology, factual plausibility, or procedure while continuing to write the positive event. This is evidence of an association between the status manipulation and readout form, **not** proof that Oracle preserves the factual polarity correctly. Both markers occur in every prompt, but order/recency heuristics remain possible explanations; the task does not isolate full logical scope understanding.

**Banks / both readers.** E49. The relation to status appears in both readers through different expressions: explicit negation for NLA, editorial fault language for Oracle. No cross-bank replication of the 38/42 versus 0/42 contrast is claimed.

**Three verbatim examples, without per-item true status:**

- E49 NLA, `f8c61dc25adf639bb30b2274`: “it is not the case that following the timestamp entry the safety interlock was disabled”
- E49 NLA, `9f0a30e49cfd308ff3af529a`: “Final fragment "it is not the case that after the calibration sequence was completed the safety interlock was disabled"”
- E49 Oracle, `8518be4fc6093e1e2e7af473`: “This violates chronological integrity. A proper log would state:”

**Novelty.** New truth-conditioned refinement of first-pass E49 P4/P8. The first pass counted negation words but could not establish whether they selected the current clause's actual status. The Oracle editorial association is a new candidate channel that a “not”-only audit misses.

**Confirmatory test on new items.** Cross clause polarity, clause order, event plausibility, and chronology independently. Use fresh benign propositions and both lexically explicit negation and paraphrases. Freeze the editorial marker before collecting outputs, and have blind humans separately score target-proposition polarity, logical scope, and commentary about prose quality or event plausibility. A genuine status-associated editorial channel should survive counterbalancing chronology and plausibility; a recency heuristic should fail when the most recent marker belongs to a closed clause.

### P3.2 — Hypothetical status is more often replaced by a story about a flawed example than carried into the reconstructed event

**Hypothesis.** The NLA sometimes converts a hypothetical-versus-asserted distinction into a genre judgment about “correct” and “incorrect” examples, leaving the event it quotes unqualified.

**Count.** All **84/84** E49 asserted/hypothetical prompts contain both “It is the case that” and “Suppose, counterfactually, that,” with their order changed. NLA readouts contain `hypothetical`, `counterfactual*`, or `suppos*` on **2/42** hypothetical and **0/42** asserted items; Oracle has **0/84** occurrences. In both NLA hits (**2/2**), “counterfactual” labels a logic-puzzle format, rather than explicitly qualifying the reconstructed final event. NLA quotes a `Final fragment` or `Final token` in **84/84** readouts, with **0/84** of those quoted spans carrying the screened modality terms, including **0/42** in the hypothetical subgroup.

The alternative error framing—`wrong`, `incorrect`, or `flawed`—occurs in NLA **24/42** hypothetical versus **9/42** asserted readouts; Oracle has **0/84**. This is a status-associated framing difference, not a count of explicit false affirmations. A quoted fragment can omit its governing clause without asserting that the event occurred. Also, the negation and hypothetical rows differ in their event content and discourse, so the contrast with P3.1 does not establish that counterfactuality is intrinsically harder than negation.

**Banks / both readers.** E49. Absence of explicit hypothetical vocabulary occurs in both; substitution into an error/example genre is primarily NLA. E49 topic-twin shares these readouts and is not an independent replication.

**Three verbatim examples, without per-item true status:**

- E49 NLA, `6c8c52f2717fc4f3552843af`: “The "counterfactual" logic puzzle format: the text contrasts correct/incorrect document types,”
- E49 NLA, `c72764bc209e13e08a0759e3`: “The "counterfactual" logic puzzle format (from the earlier "if...then" clause)”
- E49 NLA, `3311e169d2ddd3bde274b202`: “The "incorrect" example demonstrates a deliberate topic-switching error,”

**Novelty.** Refines first-pass E49 P3/P4 with truth-conditioned counts and the distinction between a modality word describing genre and modality attached to the target event. The first pass already noticed sparse counterfactual language; the proposed substitution mechanism is the hypothesis to test.

**Confirmatory test on new items.** Use the same event text under assertion, negation, counterfactual, quoted report, and question forms, counterbalancing source and scope order. Ask independent coders whether the readout attributes the status to the event, merely describes a document genre, or leaves status unspecified. Keep these scores separate from whether the event's entities and verbs are reconstructed correctly. The hypothesis predicts more genre substitutions than event-level status statements for counterfactuals, even after equalizing vocabulary and context.

### P3.3 — A retained prohibition can become the NLA's reason to predict the prohibited concept next

**Hypothesis.** The NLA can preserve the negative wording of a constraint while assigning it a different discourse function: a cue for what the response should complete or repeat.

**Count.** In E57 focus-ignore, **7/84 NLA** readouts pass a deliberately narrow screen requiring both negative-instruction wording (`do not think`, `without thinking`, or `avoid thinking`) and a completion forecast mentioning birds/avian content. The forecast screen searches `next token/word` within 180 characters, or `must be/complete/conclude` within 100 characters, before that concept. Oracle has **0/84** hits under this NLA-style wording screen; that is not evidence that Oracle lacks analogous implicit continuations. Existing judge codes call **6/7** screened NLA readouts `states_value`; the seventh is silent. The screen is an observable co-occurrence estimate, not an exhaustive semantic rate.

These readouts forecast a callback or repetition of the constraint. That can preserve negation inside the predicted text, so it is **not** a direct logical contradiction or evidence that the target model is thinking the forbidden concept. There is no measured target-model next-token agreement in this comparison. The point is the change from an instruction's prohibition to a reader's positive expectation about the next textual mention.

**Banks / both readers.** E57; the quantified formulation is NLA-specific. E61 D4's different endpoint and complete absence of concept mentions, documented in theme 6, prevents treating this as a universal white-bear result. E57 focus-ignore's failed probe gate precludes a decodable-state claim.

**Three verbatim examples:**

- E57 NLA, `1a4b0b8a51940bb2323a6eb8136782fa`: “which must be completed with "birds" to mirror the opening constraint exactly,”
- E57 NLA, `c5f40d2bae0579ada2b482bb9f2e8797`: “the next token must complete this phrase, almost certainly "birds" echoing the opening instruction,”
- E57 NLA, `1026b33c917f35d645dd65da0fc57e78`: “the next word should reference birds/avian creatures, completing the thematic callback to the opening constraint about avoiding bird-related thoughts.”

**Novelty.** Refines the first pass's instruction-echo observation with a counted same-readout combination of prohibition and affirmative continuation forecast. It contributes a discourse-role distinction, rather than a new claim that negation is simply inverted. Theme 9 addresses whether the judge should credit the resulting mentions.

**Confirmatory test on new items.** Independently vary “do not think about,” “do not mention,” “quote the instruction,” and “repeat only the unrelated sentence,” using novel concepts and matched read positions. Score preserved negative wording, predicted next mention, actual next-token probability, and eventual output separately. A new human rubric must distinguish a negated quotation from an affirmed fact and a continuation forecast from a claim about current state. This tests whether the effect is repetition-template selection, leakage into future output, or merely reader invention.

### Limits of this theme

No general polarity confusion matrix is claimed: these banks do not fully cross proposition, modality, source, and reader position. Reported-speech and question/assertion handling therefore remain confirmatory-test factors, rather than established findings here. The strongest new result is that absence of the word “not” need not imply absence of all status information. None of these analyses establishes unverbalised motivation, deception, or a model belief.

Hedge words occur in **345/500** random and **411/500** shuffled outputs. Thus exact-looking quotations and next-token uncertainty are both available as reader behavior in a placebo setting. These are descriptions of instruction-conflict genre and normative requirements, not measured refusal, deception, harm or compliance. No latent intention is established by “must.”

**Novelty:** **Grounded refinement.** The first pass already noted test/jailbreak framing. New here is the complete-population contrast against the actual source vocabulary and the own-prompt claim-level result: the most explicit Oracle attack labels are treated as unverifiable interpretations by the existing fidelity judge. This limits what the framing can tell us about evaluation awareness or unverbalised motivations.

**New-item confirmatory test:** Cross harmless versus harmful payloads with user/tool provenance and with actual instruction conflict versus merely quoted examples. Keep the payload text identical across provenance arms, and separately measure the target's ensuing refusal/compliance. Blindly score source attribution, attack interpretation, purported safety rules, normative “must” language and predicted behavior. Require a reader's safety claim to predict target behavior beyond prompt genre on fresh held-out items. If it follows only conflict wording or quoted examples, it is a genre classifier; incremental behavior prediction would be stronger monitoring evidence.

### Limits relevant to the MATS questions

These data constrain how to interpret safety vocabulary; they do not directly answer whether readers expose hidden motivations. E59's benign refusal-policy contrast is addressed in Theme 2 and does not establish an unspoken motive. E76 placebo text can generate safety-related vocabulary, but its incidental domain words are not a calibrated awareness baseline and were not promoted to another hypothesis. The absence of a demonstrated deception signal in this pass is not evidence that deception is absent from the target.

## Theme 9 — Judge and detector artefacts

These are hypotheses about measurement, not revised sealed verdicts. I read the first pass before inspecting the complete sealed native grids, their public row definitions and their unchanged codes. The estimates below are **local audit rates in deliberately selected rows**, not an estimate of the judge's error across the sprint. No new judge was called. E49 used a frozen regex rather than the later blind judge, so its problem belongs to the detector, not the judge. `count_theme09.py` reproduces the descriptive counts without executing an original scoring entrypoint.

### J1. A detector can report zero while both readers explicitly attach a type word to the tracked variable

**Hypothesis:** Some apparent complete misses are caused by narrow grammatical matching, especially when a reader says “is now” or “becomes” instead of “is a.” **New relative to the first pass**, which did not audit E49's native detector.

**Count:** E49 `var_type_at_use` has sealed probe AUROC 1.0 and frozen any-value detection **0/84 Oracle and 0/84 NLA**. A transparent search for `x is [now] [a] string/int/integer` or `x becomes [now] [a] string/int/integer` finds **39/84 Oracle and 9/84 NLA, 48/168 combined (28.6%)**. These are candidate false negatives for *type-expression detection*. They are not 48 correct answers: some reconstruct an invented program, refer to an intermediate transformation, or use a conditional. The search is deliberately narrower than all possible type paraphrases and does not estimate recall. The old pattern requires forms such as `x is a string`, `x holds a string` or `type of x is str`; it misses the added adverb and changed verb. All NLA readouts in this E49 cohort were cut at the old 128-token limit.

**Three verbatim readout excerpts (new opaque E49 identifiers):**

- `91b57a1b993d1d7f95086bf1`: `# x is now a string, y is now an int, z is now a string`
- `23f57146ed19d1d4237db65e`: `# x is now a string, y is now an int, z is now a string. Print them in order: x, y,`
- `221d0c29ebe4ba45cbf5671a`: `x becomes string "1", y becomes int 2, z becomes float 3`

**Banks/readers:** demonstrated in E49, both readers; not claimed across other banks. **MATS relevance:** “what do they find and not find”; a measured zero cannot by itself establish semantic silence.

**New-item test:** Freeze a small grammar challenge set crossing `is a`, `is now a`, `becomes`, code comments, quotations, conditionals and negations. Separately label (i) whether a type is mentioned, (ii) whether it is asserted of the current tracked variable, and (iii) whether it is true. Test the original detector and a new blind semantic rubric against two independent human coders. Then acquire genuinely new variable-tracking items and score with the frozen, validated method; do not replace E49's sealed score.

### J2. At the decision rung, answer-format vocabulary can be mistaken for the state being queried

**Hypothesis:** The judge sometimes maps a generic answer letter or an output constraint onto an unrelated property value. **Refinement of first-pass T7/E62 P3**, with full-cohort counts and two additional error mechanisms.

**Count:** Across all five E62 L4 rows, **41/420** readouts are coded `states_value`, all for the public first candidate. A census read of those **41/41** finds no semantic assertion of the row's requested state: **38/41** evidence strings contain the answer letter `A`; **2/41** cite “single-word,” transferring a constraint on the reply to bracket depth or the passage's line length; **1/41** cites entailment as evidence for grammatical tense. This is a provisional audit disagreement rate of **41/41 positive codes**, or **41/420 (9.8%) of the L4 cohort**, not an independently validated error rate. The first pass saw 31/322 and described every hit as answer-letter credit; the complete cohort reveals the broader scope-confusion mechanism. No per-item truth is needed for this audit: the relevant question is whether the public readout asserts either public property value at all.

**Three verbatim readout excerpts:**

- `99573e169dab2b256619cf44a636128f`: `{"label": "A"}`
- `25ab63b70757e67a9eb47adca4eebf45`: `The prompt asks for a **single-word** response`
- `70e346ec02cd012515826557c7f27b21`: `The sentence in the prompt is a direct paraphrase of the hypothesis. Therefore, the premise entails the hypothesis.`

**Banks/readers:** E62, Oracle only; NLA was not run in this bank. The public states are bracket depth, line length, tense, language and subject number, not a generic classifier's label. **MATS relevance:** “what do they find and not find”; decision-rung reporting estimates can contain format credit rather than state reports.

**New-item test:** Build new, counterbalanced decision tasks with arbitrary answer alphabets, reverse their mappings, and include unrelated classifier continuations containing the same letters. Keep each state's two values explicit in the rubric, require evidence to assert that state, and label reply-length versus source-line-length separately. Compare two independent humans with the unchanged and revised rubric on held-out readouts; measure false positives in the unrelated-answer controls and retention of actual state statements.

### J3. A superclass word can receive credit for a narrower target concept

**Hypothesis:** In focus/ignore scoring, a readout about generic fruit can be credited as stating *citrus*, even when no citrus instance or synonym appears. **New relative to the first pass's negation-credit observation.** This concerns semantic specificity, independently of whether negated topic mentions should count.

**Count:** In E57 `focus_ignore`, **6/84 Oracle readouts** are credited for the citrus candidate while the cited evidence says only “list fruits.” These are **6/18 (33.3%) of Oracle's `states_value` codes** in that row, or **6/25 (24.0%)** of the two readers' positive codes combined. Full-text inspection finds no citrus term or instance in these six; the non-citrus distractors do not repair that inference. The same screen yields **0/84 NLA** in E57 `focus_ignore`, **0/252 Oracle and 0/252 NLA** across the other three E57 focus arms, and **0/84 per reader** on E56 `instructed_focus`. Thus it is a small, concentrated failure, not a general reader difference. These are candidate judge false positives; they say nothing about the hidden true concept of the item.

**Three verbatim readout excerpts:**

- `90e21661979e1c7e59389ece2f904877`: `Begin generating a list of fruits.`
- `e7e2af9c0a76d3f78f2e615104e758f7`: `I will ignore the distraction and fulfill the request to list fruits.`
- `5d2c5ae2fd6f6d6487972746331c9bfd`: `Begin listing fruits.`

**Banks/readers:** observed in E57 Oracle; absent under the stated screen for E57 NLA and E56 both readers. **MATS relevance:** “what do they find and not find,” and unverbalised motivations: coarse topic evidence should not be promoted into a specific internal focus claim.

**New-item test:** Cross specific targets and superclasses on new prompts—citrus/fruit, birds/animals, and corresponding non-members—while independently varying `think`, `do not think`, `mention` and neutral wording. Include readouts that name only the superclass. Freeze a taxonomy-aware rubric that credits synonyms and actual members but not superclasses, then obtain blinded human judgments and estimate each error type separately from polarity errors.

### Interpretation limits

The three selected audits have different units: a detector-expression screen, a census of positive judge codes at one rung, and a specific superclass confusion. Their numerators must not be added into a global error rate. The first pass's both-values inflation and negation-credit concerns remain plausible, but I did not promote them to additional candidates without a new systematic adjudication. In particular, a rubric that measures *topic mention* can reasonably count a negated mention; the mistake would be interpreting that count as the model's belief or active intention. This report leaves every original code and verdict intact.

### S10.1 — Near-agreement on the coarse row map can conceal sizeable differences between readers

**Hypothesis:** A binary “reported or missed” forecast may describe a shared property-level limitation while being too coarse to choose which reader is useful on a particular property or item.

**Count:** E75 contains **35** row/state units evaluated for both readers. Their sealed binary reporting outcomes agree on **34/35**: **18/35** are reported by both, **16/35** missed by both, and **1/35** reported only by Oracle. Marginal reported counts are **19/35 Oracle** and **18/35 NLA**, so the agreement is not merely a shared all-missed base rate. Nevertheless, **5/35** units have an absolute difference of at least **0.20** between the readers' signed statement rates; **4/34** of the agreeing binary outcomes contain such a difference. The largest absolute rate gap is **0.607**. These units are rows or state/rung cells, not independent native items, and related cells share source designs.

The J forecasts agree on **35/35** common units because they use the shared property-level predictor. That agreement is a feature of the design, not independent validation. **7/35** units are forecast errors for both readers; these include **all 7/7 NLA errors**, while Oracle has **8/35** errors on the common set. This follows closely from the outcome agreement and should not be counted as a second independent statistical result. On the full, unequal pools, forecast correctness is **44/55 Oracle** and **28/35 NLA**; the sealed balanced accuracies are **0.792** and **0.802**. E75's registered rule remains **NOT EVALUABLE for both readers** because neither reaches 60 units, and the registered incremental advantage over category has intervals crossing zero. No new predictor was fitted and no sealed classification was changed.

**Banks / both readers:** E75's common comparison covers E56, E57, E59 and E73; the 20 additional E62 units belong only to Oracle and are excluded from the paired comparison. Both readers show the shared coarse map. This does not contradict theme 7's same-item complementarity: a shared row outcome leaves considerable room for different wording, different correct items and different wrong-assertion rates.

**Three verbatim public readout examples:** These illustrate the varied kinds of output compressed into a row-level outcome. They are not per-item truth labels or a released pairing table; the counts above come from the complete aggregate pool, not these examples.

- E56 NLA, `ff1667317f41fed7af43eadc21ddf6c7`: “Q&A format established: a sentence is given as context, followed by a question about the next word's part of speech, expecting a direct answer.”
- E73 Oracle, `01c1227e7e2480ac8c220bab87a753e3`: “- , effectively doing nothing, as this is the base class.”
- E73 NLA, `00ec451cddbb04c0441b696d7da2ec14`: “Wikipedia-style article structure with detailed song history, following a pattern of factual chronological narrative about "Give It Up" by Fergie.”

**Novelty and MATS relevance:** **New relative to the first pass**, which did not include E75. This constrains “what do they find and not find” and “what can NLA find that Oracle cannot”: a strong-looking common row map is insufficient to answer the reader-selection question. The explanatory alternatives include a shared information bottleneck, shared prompt families, shared scoring, and compression by the reporting threshold; this recount does not distinguish them.

**Confirmatory test on new items:** Collect new, independently designed property families with enough forecast units to satisfy the registered size and class-balance gates. Freeze property-level forecasts before seeing reader output, but evaluate continuous signed statement rates and same-item correct/wrong/abstain behavior alongside the binary verdict. Match output budgets and use independently validated human scoring. Hold out whole property families when testing a reader-specific predictor. The hypothesis predicts high binary agreement with residual differences that a shared predictor cannot resolve; disappearance of the gaps under better scoring or equal budgets would instead implicate measurement or presentation.
