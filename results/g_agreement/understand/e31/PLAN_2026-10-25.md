## Inputs and local classifier

Use the seven rows with at least one dev-valid E15 pair: prose_paren, prose_quote,
python_string, python_indent, python_depth, list_depth, table_role. The sealed E15
valid-pair mask is [0,1] in every included row. Table_column has no valid pair and
is excluded by the existing E15 gate. No validity gate is recomputed or changed.
Each row has 84 W1 dev and 84 test items, 42 per value, with disjoint template
clusters between dev and test. Exact IDs, token arrays, labels and source hashes
are checked against E15's frozen bank and the original W1 item bank.

For each row, decode only the chosen four frozen Qwen token IDs, with tokenizer
cleanup disabled and special-token skipping disabled. Train one classifier on all
84 dev suffixes. Use E1b's exact recipe: character TF-IDF 1–4 grams, case preserved,
min_df=1, L2 normalization, use_idf=True, smooth_idf=True, sublinear_tf=False;
L2 logistic regression with C=1, lbfgs, max_iter=2000, tol=1e-4,
random_state=20261023. Treat convergence warnings as errors. Vocabulary, IDF and
coefficients fit on dev only; no tuning, cross-validation or sign selection.
Installed scikit-learn 1.9.1 matches E1b's recorded version.

The probability margin is class-independent confidence `abs(p_A - p_B)`, with
A equal to the first value in the frozen W1/E15 value order. For each row, freeze
the median of its in-sample dev probability margins. A test item is informative
iff its margin is **strictly greater** than that cutoff; equality goes to the
uninformative stratum. This follows the requested all-dev fit and dev cutoff;
it does not use true-label-signed confidence or a test quantile. Empty or
single-class test strata remain not evaluable; do not change a cutoff to rescue
them or force equal stratum sizes.

Seal fitted vocabulary, IDF, coefficients, dev cutoffs and item assignments before
reading E15's per-item continuation outcomes. Large fitted models, suffixes and
item ledgers stay in ignored cache; small cutoff/provenance/seal files are saved.

## Sealed continuation outcomes and uncertainty

Primary outcome: Oracle layer-44 `true` scores from E15. Each stored pair score is
already the signed **sum** of candidate-token log probabilities for A minus B.
Average only the frozen valid pair margins, then calculate signed AUROC against
value A within each test stratum. Never apply E25's per-token normalization,
select a pair using E31 outcomes, reverse a sign, or replace an AUROC by 1−AUROC.

Report each stratum's n, n_A, n_B, AUROC and 95% percentile interval from 2,000
IID item-bootstrap draws within that stratum, seed 20261025. Class labels are
resampled with the item, without enforcing class balance. One-class bootstrap
draws are undefined and counted; percentile intervals use finite draws. A
stratum with fewer than two classes has no AUROC or interval. Classifier and
cutoff stay fixed during bootstrap. These are item intervals conditional on the
fitted classifier, not E15's original template-cluster intervals.

The Oracle informative-minus-uninformative AUROC difference uses independent
resampling within the two strata. Oracle's already-sealed random-donor arm is a
descriptive control, with the same resampled recipient indices used for the
paired true-minus-random contrast. NLA `true` continuation AUROC is retained in
an appendix as descriptive and off its native explanation format. No new donor
mapping or model score is generated. Unstratified true Oracle/NLA and Oracle
random-donor points must reproduce the sealed E15 metrics before interpretation.

Apply the registered point predictions per row: local cue means informative
AUROC ≥0.75 and uninformative ≤0.60; remote state means both ≥0.70. Report how
many evaluable rows satisfy each without inventing a pooled or majority verdict.
All seven rows remain visible, including low-performing and unevaluable rows.
Intervals and contrasts are unadjusted descriptive estimates. The split is
observational; it does not by itself establish a causal source of the signal.
