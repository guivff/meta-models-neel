# E36 v2 authorship boundary — 2026-10-25

This chat previously worked on W1-derived experiments and therefore has historical
W1 result context. It cannot claim never to have seen those results. E36 item
writing is assigned to newly spawned agents with **no inherited conversation
history**. The parent handles files, hashes and operational integration and does
not supply prior item text, examples, scores or result summaries to the authors.

The state-row author owns prose_paren, python_string, table_role and python_indent.
The other-row author owns table_column, list_index, prose_sentiment and prose_topic.
Each author is restricted to the E36 registration, the permitted source extract,
the eventual authorized definition packet and its own newly written files.
Neither author may open W1 renderers, item banks, scores, reports or caches. Reader
configuration is handled separately and is not supplied to item authors.

The permitted extraction used Python AST docstrings and COMMENT tokens within
render_body. It did not import or execute w1_templates.py and did not display or
copy renderer body strings. At the inspected source hash, those docstrings and
comments do **not** contain the requested row definitions or value bins. Both
authors read the extract and stopped before writing any items. The parent asked
for the exact definitions/bins or authorization for a metadata-only extraction;
that answer must be recorded before DEFINITION_PACKET.json is marked authorized.

The bank builder requires exactly 12 new families ×7 fillers ×2 values for each
of the eight rows, six families per split. It freezes all authored text and source
hashes before calling automatic label checkers. No original W1 text is used for
deduplication, similarity screening or tuning. Label-check failure is retained and
blocks launch; no item is silently discarded or replaced. Tokenization is CPU-only
and uses the pinned Qwen tokenizer without a chat template or truncation.

Raw authored items, tokenized inputs, labels and per-item label-check evidence go
to ignored cache. Small manifests, source, checks and the integrator launch request
are committed. There is no model, GPU or reader-based item screening.
