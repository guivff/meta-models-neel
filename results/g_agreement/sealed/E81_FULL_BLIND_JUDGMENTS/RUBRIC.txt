# E56 shared blind rubric v1 — frozen before readouts

Use exactly this rubric for both readers and every arm. Judge packets contain only an opaque record ID, the property being tested, the two value descriptions in frozen A/B order, and the native readout text. Never disclose reader identity, full/J/nonJ arm, true label, source item, repetition number, other readouts, probe result or J scores. Code each record independently. Do not infer correctness: label joining happens after judgments are sealed.

Return exactly one category and the explicitly stated value set:
- `states_value`: the readout explicitly asserts a value of the target property. `values` is `["A"]`, `["B"]`, or `["A","B"]`. Mere mention of a relevant word inside an example is insufficient. A negated assertion of A is not an assertion of A; credit B only if it explicitly entails B under the supplied binary property definition.
- `names_property_without_value`: explicitly identifies the target property but states neither value. `values=[]`.
- `exhibits`: enacts the target feature without stating it (e.g. French prose without saying it is French, a past-tense passage without identifying tense, or completing a rhyme). `values=[]`.
- `silent`: none of the above; unrelated material, refusals, incomprehensible or empty output. `values=[]`.

Priority is states_value > names_property_without_value > exhibits > silent when multiple apply. If both incompatible values are asserted, retain both; do not adjudicate which was intended. Distinguish current state from descriptions of archived/hypothetical text when the readout explicitly makes that distinction. An assertion about an unrelated property gets no value credit. Use the supplied property definition, not knowledge of the item or experimental prediction.

For every non-silent code, supply an exact supporting substring of the readout as `evidence`; use an empty string for silent. Do not repair incomplete readouts. A malformed NLA explanation is flagged in custody metadata and still receives the same rubric; it is not dropped.

Output JSON records: {"id": opaque_id, "category": one_of_the_four_categories, "values": [], "evidence": "verbatim substring"}. Exactly one output per opaque ID. Seal the complete judgment file, rubric hash and blind-packet hash before joining labels. No regex fallback, reader-specific prompts or post-outcome rubric changes.

Repeated readouts retain a hidden common item/direction ID. Eight greedy outputs are repeated observations, not eight independent items. The injection arm has twelve class directions across six rows, each under three manipulations, not forty items per row.


A value mentioned only inside a negation, a prohibition or a quoted instruction (e.g. 'do not think about birds', 'X is not the answer') does not count as stating that value.
A bare option letter, label or format token (e.g. ': A', '(b)', 'Option 1') does not count as stating a value unless the readout says what it stands for.
