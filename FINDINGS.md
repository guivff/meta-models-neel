## C1: what was computed

**R-IN1 MET in all three bookkeeping rows.** Per row, fit a separate probe at each Oracle decoder block/position using dev data; freeze all fits before evaluating the full test grid. The reported maximum is the registered any-layer threshold summary, not a dev-selected layer estimate. See [probe recipe](results/g_agreement/understand/e113/probes226/probes.py) ([original `c16db5689937c1895c9cb6d605bc39df19f15411`](https://github.com/guivff/activation-readers/blob/c16db5689937c1895c9cb6d605bc39df19f15411/results/g_agreement/understand/e113/probes226/probes.py)) and [frozen run adapter](results/g_agreement/understand/e113/probes226/run_once.py) ([original `c16db5689937c1895c9cb6d605bc39df19f15411`](https://github.com/guivff/activation-readers/blob/c16db5689937c1895c9cb6d605bc39df19f15411/results/g_agreement/understand/e113/probes226/run_once.py)) and the aggregate grid. The state being linearly decodable does not establish that generation uses it. The exact layout binder/final source was written after capture; the independent review retains that chronology qualification.

## C2: what was computed

Oracle belief-naming rate is 60/92 versus forecast 47/167 among each output’s own value-naming subset: **difference 0.370737**, paired source-item bootstrap 95% CI [0.253859, 0.485517], 5,000 draws, seed 0. All 199 source items remain represented; naming denominators differ. [Analysis source](projects/g_agreement/e107b_analysis/) ([original `c16db5689937c1895c9cb6d605bc39df19f15411`](https://github.com/guivff/activation-readers/blob/c16db5689937c1895c9cb6d605bc39df19f15411/projects/g_agreement/e107b_analysis/)).

This is descriptive and does not replace E107’s registered primary. The §248A review reports the observed unconditional gain as 0.081060; its full-item worst-case bootstrap envelope includes zero. Missing and non-naming outputs are not silently scored zero. The baseline and judge share a model family, with unknown confounding direction. Read the review/companion alongside the conditional headline.

## C5: what was computed

For each fact item, restoration is `(steered − patched_restore) / (steered − clean)` using target-minus-original full-continuation log odds; take the itemwise ratio before the median and item bootstrap. At block 56 the median is **0.876478**, 95% CI [0.849549, 0.903212]. Two control patch types satisfy the registered bounds at all tested layers. [Analysis source](projects/g_agreement/e126_analysis/) ([original `c16db5689937c1895c9cb6d605bc39df19f15411`](https://github.com/guivff/activation-readers/blob/c16db5689937c1895c9cb6d605bc39df19f15411/projects/g_agreement/e126_analysis/)).

R-MED1 is **MET for fact recall**; language and insertion results are descriptive. Preserve undefined-ratio handling, serial-clean versus batched capture differences, and the reviewer’s normalization/cast qualifications. This is mediation of an answer-preference effect, not a demonstrated repair of reader text or proof that every model state is available to the reader.
